# INDM

**A fast, lightweight download manager for Windows.**
Faster downloads, resume, queues, browser extension, and control from your phone. English and Persian interface.

## English

### Features

- **Download accelerator:** up to 32 connections per file, resume after pause or crash, automatic reconnect
- **Mirrors:** several addresses for one file; if one fails, INDM continues from the next
- **Queues and scheduling:** start times, speed limits, shut down when finished
- **Checksum check** (MD5, SHA-1, SHA-256, SHA-512)
- **Browser extension** for Chrome, Edge, Brave and Firefox
- **Video download** with yt-dlp
- **Phone control:** scan a QR code and manage downloads from your phone, with an Android app that can also notify you and copy finished files to the phone
- **Automatic updates**, dark and light themes, tray icon, English and Persian (Jalali dates)

### Download and install

Get the files from the [latest release](../../releases/latest):

| File | What it is |
| --- | --- |
| `INDM_Setup.exe` | Installer |
| `INDM.exe` | Portable version, no install needed |
| `chrome_extension.zip` | Extension for Chrome, Edge and Brave |
| `firefox_extension.zip` | Extension for Firefox |

Windows 10 or newer. Windows or your antivirus may warn about an unsigned program; this is normal for a small independent project.

### Browser extension

Extract the zip, open `chrome://extensions` (Edge: `edge://extensions`), turn on *Developer mode*, choose *Load unpacked* and select the folder. Then copy the pairing code from INDM (**Tools › Browser extension**) into the extension options.
Firefox: `about:debugging` › *This Firefox* › *Load Temporary Add-on* › pick the zip.

### Phone control

In INDM open **Tools › Phone control**, turn it on and scan the QR code with your phone on the same Wi-Fi. Use it on your own network only.

## فارسی

<div dir="rtl">

### امکانات

- **شتاب‌دهندهٔ دانلود:** تا ۳۲ اتصال برای هر فایل، ادامهٔ دانلود بعد از توقف یا خرابی، اتصال مجدد خودکار
- **آینه‌ها:** چند آدرس برای یک فایل؛ اگر یکی خراب شد، INDM از بعدی ادامه می‌دهد
- **صف و زمان‌بندی:** زمان شروع، محدودیت سرعت، خاموش شدن بعد از پایان
- **بررسی چک‌سام** (MD5، SHA-1، SHA-256، SHA-512)
- **افزونهٔ مرورگر** برای Chrome، Edge، Brave و Firefox
- **دانلود ویدیو** با yt-dlp
- **کنترل با گوشی:** کد QR را اسکن کنید و از گوشی دانلودها را کنترل کنید؛ برنامهٔ اندروید هم اعلان می‌دهد و فایل‌های کامل‌شده را روی گوشی ذخیره می‌کند
- **بروزرسانی خودکار**، پوستهٔ تیره و روشن، آیکون سینی، رابط فارسی و انگلیسی (تاریخ جلالی)

### دانلود و نصب

فایل‌ها را از [آخرین نسخه](../../releases/latest) بگیرید:

| فایل | توضیح |
| --- | --- |
| `INDM_Setup.exe` | نصب‌کننده |
| `INDM.exe` | نسخهٔ قابل‌حمل، بدون نیاز به نصب |
| `chrome_extension.zip` | افزونه برای Chrome، Edge و Brave |
| `firefox_extension.zip` | افزونه برای Firefox |

ویندوز ۱۰ یا جدیدتر. ممکن است ویندوز یا آنتی‌ویروس برای برنامهٔ بدون امضا هشدار بدهد؛ برای یک پروژهٔ مستقل کوچک طبیعی است.

### افزونهٔ مرورگر

zip را باز کنید، `chrome://extensions` (در Edge: `edge://extensions`) را باز کنید، *Developer mode* را روشن کنید، *Load unpacked* را بزنید و پوشه را انتخاب کنید. بعد کد اتصال را از INDM (**ابزارها › افزونهٔ مرورگر**) در تنظیمات افزونه بچسبانید.
Firefox: `about:debugging` ‹ *This Firefox* ‹ *Load Temporary Add-on* ‹ فایل zip.

### کنترل با گوشی

در INDM به **ابزارها › کنترل با گوشی** بروید، روشنش کنید و با گوشی روی همان وای‌فای کد QR را اسکن کنید. فقط روی شبکهٔ خودتان استفاده کنید.
